# Dafiyu Control Center 0.3.2

本版本清理了与普通用户使用无关的界面提示。

## 变更

- 移除首次设置/完成页的“分享安装包”提示
- 移除“安装包里不包含账号/密码”的开发者侧提醒
- 移除开发模式（未打包）的技术提示
- “仓库 backups”改为“备份目录”
- “仓库自带的启动脚本”改为“项目自带的隐藏启动脚本”

保留的是用户需要知道的安全边界：不显示密码/令牌、不覆盖已有环境、安装完成不自动启动服务。

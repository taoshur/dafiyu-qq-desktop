# Memory V4 模型回答评测

## 目标

把“检索命中”与“模型回答正确”分开评测，避免用召回率冒充回答质量。

## 脚本

```powershell
npm run eval:answers
```

默认不调用模型，只输出 `not-run`。设置环境变量后才调用：

```powershell
$env:DEEPSEEK_API_KEY = "..."
npm run eval:answers
```

不会读取或修改生产 `memory.db`。

## 用例类型

- 不存在事件：应说“没有相关记忆”，不得编造
- 人物归属：应把事实归给正确的人
- 时间错误：昨天/今天不得混用
- 无依据补充：没有上下文时不得使用“一定是/应该是/肯定”

# Dafiyu Control Center 0.8.9

## MaiBot 记忆一键导入

记忆页新增「导入 MaiBot 记忆」：

- 选择 `data/MaiBot.db` 或兼容的 SQLite 记忆库
- 自动识别 `chat_history` 新旧字段布局
- 也兼容 `paragraphs` 表
- 导入前预览数量和样本
- 导入结果写入**待审核候选**，不直接写正式 facts/events
- 不修改人格强度、traits 或关系基线
- 自动去重，重复导入不会重复生成候选
- 导入前自动备份目标记忆库

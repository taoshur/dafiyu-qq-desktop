# Dafiyu Control Center 0.3.1

本版本加入“大肥鱼对用户的称呼”设置。

## 新增

- 首次设置向导第一步询问称呼
- 默认“爸爸”，输入长度最多 16 个字符
- 首页问候语使用该称呼
- 配置页可随时修改
- 只写入桌面配置，不写入 QQ 配置、不上传

## 兼容

- 旧配置没有 `ownerTitle` 时自动使用“爸爸”
- 损坏/空值回退“爸爸”
- 不影响服务控制、Memory、备份和安装任务

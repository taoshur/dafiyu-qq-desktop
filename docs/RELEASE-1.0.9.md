# Dafiyu Control Center 1.0.9

## 日记页面适配大屏

- 日记页不再限制 1180px 宽
- 左侧列表 + 右侧正文撑满内容区
- 空状态高度跟随窗口
- 大屏下不再出现大面积空白

## 记忆自动审核设置

长期记忆页新增「自动审核设置」：

- 开关
- 可信度阈值
- 每日上限（0 = 不限）
- 审核类型：事实 / 事件
- 保存到 qqbridge 配置，重启 qqbridge 生效

## 更新公告

- 每次检测到新 Release 时，启动后弹出更新公告
- 同一个版本只弹一次
- 公告内容来自 Release notes
- 已安装的新版本也会显示一次更新内容

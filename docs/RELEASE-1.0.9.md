# Dafiyu Control Center 1.0.9

本次更新主要是管理器体验优化。

## 日记

- 日记页适配大屏，不再限制 1180px
- 左侧列表 + 右侧正文撑满内容区
- 空状态高度跟随窗口
- 空列表不再重复显示两个刷新按钮

## 长期记忆

- 新增「自动审核设置」
  - 自动审核开关
  - 可信度阈值
  - 每日上限（0 = 不限）
  - 审核类型：事实 / 事件
- 修复已确认事实点击后看不到详情的问题
- 已确认事实 / 事件重新支持来源消息
- 来源消息改为内部滚动区域，避免详情页过长
- 旧数据没有来源链时显示明确说明

## 外观

- 主题从下拉框改成独立「外观」卡片
- 深色 / 浅色 / 跟随系统三张预览卡片
- 点击立即预览，保存后生效

## 更新提示

- 取消启动更新公告
- 取消顶部更新横幅和 toast
- 保留「关于 → 版本与更新」中的手动检查

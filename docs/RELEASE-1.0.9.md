# Dafiyu Control Center 1.0.9

## 日记页面适配大屏

- 日记页不再限制 1180px 宽
- 左侧列表 + 右侧正文撑满内容区
- 空状态高度跟随窗口

## 记忆自动审核设置

长期记忆页新增「自动审核设置」：

- 开关
- 可信度阈值
- 每日上限（0 = 不限）
- 审核类型：事实 / 事件
- 保存到 qqbridge 配置，重启 qqbridge 生效

# Dafiyu Control Center 0.9.4

## 服务页

- 顶部新增在线状态摘要
- 新增「一键启动未运行服务」
- 启动仍按 SnowLuma → qq-bridge 依赖顺序执行
- 不包含 DSH 的重复启动

## 配置数据管理

- 新增「导出桌面配置」
- 新增「导入桌面配置」
- 导出内容仅包含：
  - 称呼
  - 服务路径
  - 启动/恢复开关
- 不包含 API Key、token、Cookie 或记忆库
- 导入前显示字段差异
- 导入前确认，不会自动启动或重启服务
- 导入后立即刷新桌面设置

## 其他

包含 0.9.3 的轮询状态保留、导航分组、总览状态摘要、记忆左右分栏、配置字段标签，以及 0.9.0 的快速退出和手把手教程。

# Dafiyu Control Center 1.0.8

## 日记

- 新增「日记」页面
- 大肥鱼没有固定写日记时间，想写时才写
- 新增 `qq_diary_context` / `qq_diary_write` 工具
- 日记保存到 `qqbridge/state/diary.db`
- 支持标题、正文、心情标签、当天片段
- 管理器可查看日记列表和正文
- 管理器提供「允许大肥鱼自己写日记」开关

## 边界

- 不自动发送到 QQ
- 不写入事实 / 事件
- 不进入自动审核
- 不根据日记修改人格
- 不设固定定时任务

# Dafiyu Control Center 0.3.3

本版本把「长期记忆」页面改成普通用户能看懂的说法。

## 变更

- `observeOnly` → **观察模式**，并说明“只生成候选，不自动写入”
- `facts / events` → **已确认事实 / 已记录事件**
- `待审核` → **待你确认**
- `applied` → **已采纳**
- `生产库` → **真实记忆（只读）**
- `隔离测试库` → **练习副本**
- `主体` → **涉及谁**
- `作用域` → **生效范围**
- `置信度` → **可信度**
- `时间精度` → **时间准确度**
- `完整性` → **数据库自检**
- 表格标签：`group:…` → `群聊 …`，`pending` → `待确认`，`valid` → `校验通过`
- 审核按钮：`批准并写入测试库` → **确认并写入练习副本**
- 拒绝按钮：`拒绝` → **不记住这条**

## 保持不变

- 真实记忆仍然只读，桌面不能修改、删除或批准
- 审核只写练习副本
- 不会导出聊天证据

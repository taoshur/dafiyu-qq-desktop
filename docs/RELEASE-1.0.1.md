# Dafiyu Control Center 1.0.1

## 主题与基础体验

- 新增深色 / 浅色 / 跟随系统三种主题
- 配置页可直接切换主题，设置持久化
- 统一语义颜色、控件高度、字号和焦点样式
- 浅色主题使用独立语义 Token，不再依赖被强制深色覆盖的媒体查询
- 页面导航按「机器人 / 设置与启动 / 记忆 / 数据 / 其他」分组

## 页面单元

- 总览状态摘要与下一步主操作
- 新手清单：检查环境、启动服务、审核记忆、创建备份、教程
- 服务页一键启动未运行服务
- 记忆页列表 + 详情左右分栏，隐藏空字段
- 配置页字段标签、主题选择、桌面配置导入导出
- B 站观看台账显示具体视频/热词列表；无 BV 的列表自动隐藏 BV 列

## 教程

- 聚光灯教程保留
- 关键目标使用稳定的 `data-guide-target`
- 主题切换后教程仍可定位

## 其他

- 包含 0.9.4 的配置数据管理
- 包含 0.9.3 的轮询状态保留、状态摘要和记忆分栏
- 包含 0.9.0 的快速退出和手把手教程

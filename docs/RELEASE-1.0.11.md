# Dafiyu Control Center 1.0.11

## 好友与白名单

新增「好友与白名单」设置：

- 自动通过安全好友申请
- 每天最多自动通过数量

自动通过条件：

- 有正常的验证消息
- 不含验证码、转账、兼职、广告、外链等风险词
- 未达到每日上限

通过后立即写入私聊白名单。

不会自动通过：

- 空验证消息
- 风险词申请
- 超过每日上限的申请

这些仍交给大肥鱼判断。

## 修复

- 修复好友通过后，把 `flag` 当 QQ 号去查白名单的问题
- 现在通过时直接从待处理申请取申请人 QQ 并立即加白名单

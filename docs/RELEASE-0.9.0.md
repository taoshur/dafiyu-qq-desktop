# Dafiyu Control Center 0.9.0

## 退出体验

- 「仅退出界面」立即退出，不再等待服务
- 「退出并停止我启动的服务」改为快速路径：
  - 只结束本软件启动且身份校验通过的进程
  - 不再等待正常退出超时
  - 最多约 3.5 秒完成退出
- 关闭窗口时提示：已隐藏到托盘，机器人仍在运行
- 托盘菜单明确区分「仅退出界面」和「退出并停止服务」

## 手把手新手教程

- 新增聚光灯式新手教程
- 覆盖：三个服务、服务页、真实控制、启动顺序、长期记忆、MaiBot 导入、关闭/退出
- 用户可以点击真实按钮推进；教程不会代替用户执行启动/停止/批准
- 支持上一步、跳过、退出和重新观看
- 首次启动自动提示，关于页可重播
